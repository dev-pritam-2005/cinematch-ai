# Dataset folder

Place these two files here (they are git-ignored and not distributed with this project):

- `tmdb_5000_movies.csv`
- `tmdb_5000_credits.csv`

Get them from the **TMDB 5000 Movie Dataset** on Kaggle: https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata
(free account; read the dataset's terms on that page). To keep the files elsewhere, set `CINEMATCH_DATA_DIR`.
